## 1. 项目定位

**Tower**（AI 智能体 mod，Minecraft 1.20.1 NeoForge）：让 AI 像**一起玩的朋友**——既能自主生存（采集/合成/建造/战斗），也能在聊天中听指令、回话，人设可随时更换。

## 3. 架构（三层 + 护栏）

```
AI 大脑（Python，打包 exe）          ← DeepSeek：flash 思考 + vision-exp 看图（单图 384 token）
        ↕ WebSocket（Tower 协议 v1，端口 24778）
Tower mod（游戏内，本项目）          ← 原生：寻路/感知/截图/背包快照
        ↕ 转发（WS 客户端连 24777）
前置 Keyboard mod（v2 完整版）       ← 执行层：19 个动作原样透传
        ↓ 合法玩家输入
Minecraft 1.20.1
```

硬编码安全护栏（不经过 LLM）：低血量自动撤退/进食、岩浆紧急脱困、AI 失联自动归零。

## 4. 协议 v1 要点（定稿）

- **19 动作转发**（前置原样透传）+ **6 个原生动作**：`move_to`（寻路自动驾驶/路径点）、`raycast`、`get_blocks`、`get_entities`、`screenshot`、`get_state`（扩展快照：背包 0-40 槽/经验/药水/群系）
- **寻路**：原版 `PathFinder` + 自动开木门 + 卡住重算 + 手动干预（前进/左右=暂停、后退=取消）+ 7 种寻路事件
- **安全**：断线主动归零序列（**补了前置不归零 attack hold 的盲区**）+ 断开前置双保险；仅 127.0.0.1 + token；无作弊能力
- **已知限制**：铁门/活板门不处理、梯子 **v1.1**、不自动搭方块（但 AI 可 interact_block 铺路后重寻路）
