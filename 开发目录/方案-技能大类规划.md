# 技能大类规划（对齐 Issue #1 分层提案）

> 日期：2026-08-28 · 状态：待确认 · 依据：keeper-awa Issue #1「技能体系重构：按大类分层 + 工作流编排」+ 用户明确方向

## 分层架构（Issue #1 共识）

```
LLM 排 2-4 个大类阶段（获取材料 → 生产 → 交付）
        │
        ▼
复合技能内部 = 确定性流水线（检查→分支→执行→验证，可调其他复合技能）
        │
        ▼
原子工具/动作（move_to / attack / search_find / get_state / craft ...）
```

## 需要做的大类（用户确认 + 推演）

### 🥇 一、物品合成 craft_chain（用户明确，优先级最高）

**范围**：背包四格合成 + 工作台三乘三合成，背包优先；无原材料则收集。

**流程**：
1. `get_state` 查原材料是否足够
2. 查配方表（kc.py）判断 2x2（背包四格直接 craft）还是 3x3（需工作台）
3. 2x2 → 直接 `craft`（个人合成格）；3x3 → 无工作台先 `run_skill(make_crafting_table)`
4. 缺材料 → `run_skill(mine_ore)` / `run_skill(mine_wood)` 收集 → 再合成
5. 验证成品入背包

**✅ 已实现（2026-08-28）**：`kc.py` 配方表 + `craft_chain.py` 复合技能（2x2 背包优先 / 3x3 自动摆工作台 / 缺木材自动砍树合成）；圆石/铁锭收集待 `mine_ore` 接入。

### 🥈 二、挖矿 mine_ore（用户明确，优先级次之）

**范围**：检查矿物名字 → 确定生成范围（Y 层）→ 目标矿石 → 所需工具（镐等级）→ 无合适镐子自动收集材料合成。

**流程**：
1. 知识表 `kc.ore(ore)`：Y 层 / 掉落物 / 镐等级
2. 检查镐等级：不够 → `run_skill(craft_chain, {target: 对应镐})` 自动合成
3. 按 Y 层搜索（get_blocks + search_find）
4. 挖掘（mine_wood `_mine_block` 复用）+ 验证掉落

### 🥉 三、方块交互 interact（用户明确：容器交互、耕地）

**范围**：容器交互（箱子/熔炉/漏斗取放）+ 耕地（锄头耕地/播种/收获）。

**流程**：
- **容器**：`interact_block` 打开 → 取/放（move_item）→ 关闭
- **耕地**：`use_item` 用锄头耕地 → 播种 → 等待 → 收获

### 四、拾取 pickup（现状已内嵌，建议独立成类）

现有 `pickup_nearby()` 在 `_base.py`，`mine_wood` 挖完自动调。建议独立为可复用大类（战斗/种植后也要捡掉落）。

### 五、战斗 battle（规划，暂缓）

**范围**：索敌 → 接近 → 攻击 → 低血撤退。依赖 `get_entities` + `attack`，但**前置 mod 攻击能力待实机验证**（挖掘攻击复用中），建议后续再评估。

### 六、放置/建造 place（规划，暂缓）

**范围**：放置方块（铺路/建造/搭高）。依赖 `interact_block` + 手持方块切换。Issue #1 列为 interact/place，建议后续。

### 七、导航/渡水 navigation（已有，不重构）

现有 `move_to` + `cross_water` 已覆盖，作为原子能力保留，不单独成类。

## 知识数据表 kc.py（新增，全技能共享）

| 表 | 内容 | 先覆盖 |
|---|---|---|
| 矿物表 | 矿物 → {Y层范围, 掉落物, 镐等级, 是否需冶炼} | iron_ore/gold_ore/diamond_ore/coal_ore/cobblestone |
| 配方表 | 物品 → {材料+数量, 格子(2x2/3x3), 需工作台} | 木板/木棍/工作台/木镐/石镐/铁镐/熔炉 |
| 工具进度链 | 木→石→铁→钻石 各级镐的材料与前置 | 镐进度链 |
| 材料来源 | 圆石=挖石头、铁锭=铁矿+熔炉冶炼 | 基础来源 |

## 落地顺序（建议）

1. **`kc.py` 知识表**（矿物 + 配方 + 工具链，先覆盖挖矿与基础合成）
2. **`mine_ore.py`** 挖矿复合技能（流水线样板）
3. **`craft_chain.py`** 合成复合技能（依赖 mine_ore，成闭环）
4. **`interact`** 容器 + 耕地（第二批次）
5. 实机验证：挖圆石/铁矿 → 合成石镐/铁镐/熔炉
6. 战斗/放置 待上述稳定后再规划
