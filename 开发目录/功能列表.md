## 1. 前置 mod 已有能力（复用，不改动）

> 详情以《前置mod协议\最终协议.md》v2 为唯一事实来源。

### 动作（18 个，全部转发复用）

| 类别 | 动作 |
|---|---|
| 持续状态 | move、jump、jump_once、sneak、sprint、swim、fly、fall_fly、look_at（目标锁定跟踪） |
| 瞬时动作 | attack（once/hold/release 挖掘）、use_item、interact_block、interact_entity、drop、hotbar、chat |
| 背包（v2.1） | equip、move_item（槽位 0-40）、craft（按配方合成） |
| 查询 | get_state（最小快照）、set_push（pos 推送开关） |

### 事件（9 个，全部中继复用）

`player_ready` / `pos`（节流 0.5s）/ `chat` / `damage` / `death` / `respawn` / `game_mode` / `mine`（挖掘进度）/ `mine_done`

### 错误码（12 个）

`101-105`（消息/参数类）、`201`（鉴权）、`301-304`（状态/目标类）、`401`（内部）

### M2 感知层 ✅

| 功能 | 说明 | 状态 |
|---|---|---|
| `raycast` | 准星射线扫描：命中方块/实体、距离、命中面 | ✅ M2 |
| `get_blocks` | 周围非空气方块列表 `{pos,id}`，半径可调（默认 8，防超 64KB 上限），附脚下/面前/头上方块 | ✅ M2 |
| `get_entities` | 附近实体列表：类型/位置/血量/名字，可过滤（category/hostile 映射待怪物场景补验） | ✅ M2 |

### M3 导航层（move_to）✅

| 功能 | 说明 | 状态 |
|---|---|---|
| 寻路计算 | 原版 `PathFinder` + `WalkNodeEvaluator`（僵尸 dummy 实体代理，不加入世界），主线程同步计算 | ✅ M3 |
| 自动驾驶 | 沿路径点行走：look_at 对准下一节点 + move 前进（经转发链路执行）+ 卡住自动跳跃/重算 | ✅ M3 |
| 自动开木门 | 路径穿过关着木门时自动右键开门（WOODEN_DOORS tag + 节流；铁门/活板门原版寻路避开） | ✅ M3 |
| 路径点模式 | `mode:"waypoints"` 只返回路径，不走动 | ✅ M3 |
| 手动干预 | 前进/左右键=暂停（松手继续，走远重算）；后退键=取消（D5） | ✅ M3 |
| 寻路事件 | `path_found`（含路径点）/ `path_progress` / `path_reached` / `path_failed` / `path_cancelled` / `path_paused` / `path_resumed` | ✅ M3 |
| 断线归零 | 大脑断线 → Tower 主动归零序列（补 attack hold 缺口）→ 断开前置双保险 → 清导航状态 | ✅ M3 |
| 已知限制 | 铁门/活板门不处理；梯子攀爬 v1.1 规划（自定义 NodeEvaluator）；不自动搭方块（AI 可 interact_block 铺路后重寻路） | 📝 v1.1 |

### M4 视觉层 ✅
