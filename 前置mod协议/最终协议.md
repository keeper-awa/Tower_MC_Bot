# Keyboard Mod 通信协议 v2（最终协议）

> 版本：2.0（定稿，实施严格按此实现）
> 配套文档：《开发步骤规划.md》

---

## 1. 概述

| 项 | 值 |
|---|---|
| 传输 | WebSocket（服务端 = Mod，客户端 = 后台 AI 进程） |
| 地址 | `ws://127.0.0.1:24777/?token=<TOKEN>`（端口可配置） |
| 编码 | UTF-8 JSON，单条消息 ≤ 64KB |
| 会话 | 同一时刻仅一个客户端；新连接将挤掉旧连接 |
| 协议版本 | `protocol: 2`（hello 中宣告，破坏性变更时递增） |

---

## 2. 连接与鉴权

1. 客户端携带 token 发起连接（`?token=xxx`）。
2. 服务端立即返回握手结果：

   ```json
   // 成功
   {"type":"hello","ok":true,"protocol":2,"mod":"keyboard","version":"0.1.0"}
   // 失败（随后断开）
   {"type":"hello","ok":false,"error":"auth_failed"}
   ```

3. 鉴权通过后，若已在世界中，推送 `player_ready` 事件（见 §7）。
4. **心跳**：客户端每 ≤30s 发送 `{"type":"ping"}`，服务端回 `{"type":"pong"}`；服务端 60s 未收到任何消息则断开。
5. **断线清理**：连接关闭（不论原因）时，所有持续输入归零（`move/jump/sneak/...` 恢复默认），可在配置中关闭。
6. **重连**：token 不变，直接重连；重连后需重新 `get_state` 同步状态。

---

## 3. 消息类型

| type | 方向 | 说明 |
|---|---|---|
| `request` | 客户端 → 服务端 | 动作请求 |
| `response` | 服务端 → 客户端 | 动作响应（按 id 匹配） |
| `event` | 服务端 → 客户端 | 事件推送 |
| `ping` / `pong` | 双向 | 心跳 |
| `hello` | 服务端 → 客户端 | 握手宣告 |

---

## 4. 请求与响应格式

**请求：**

```json
{"id": 1, "action": "move", "params": {"forward": 1}}
```

**成功响应：**

```json
{"id": 1, "ok": true, "result": {"applied": {"forward": 1, "backward": 0, "left": 0, "right": 0}}}
```

**失败响应：**

```json
{"id": 1, "ok": false, "error": {"code": 103, "message": "value 超出范围 0..1"}}
```

规则：
- `id`：客户端自增，响应原样带回。
- 动作在游戏主线程**按到达顺序串行执行**，响应在执行完成后返回。
- 未知字段忽略；缺少必填字段 → `102`。

## 5. 动作定义

### 5.1 持续状态类

> 设置后**保持**，直到再次设置、断线归零或玩家手动操作覆盖。

#### move — 移动（全量覆盖四轴）

```json
{"id": 1, "action": "move", "params": {"forward": 1, "left": 0.5}}
```

| 字段 | 必填 | 范围 | 说明 |
|---|---|---|---|
| forward | 否 | 0..1 | 前进力度（未传视为 0） |
| backward | 否 | 0..1 | 后退力度（未传视为 0） |
| left | 否 | 0..1 | 左移力度（未传视为 0） |
| right | 否 | 0..1 | 右移力度（未传视为 0） |

- 语义：**全量覆盖**——未传字段一律置 0，避免叠加歧义。
- 力度 = 玩家移动速度 × value（1 = 全速）。
- 响应：`{"applied": {"forward":1,"backward":0,"left":0.5,"right":0}}`

#### jump — 持续跳跃

```json
{"id": 2, "action": "jump", "params": {"value": true}}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| value | 是 | true = 按住跳跃，false = 松开 |

- 响应：`{"applied": {"value": true}}`

#### jump_once — 单次跳跃

```json
{"id": 3, "action": "jump_once", "params": {"ticks": 4}}
```

| 字段 | 必填 | 范围 | 说明 |
|---|---|---|---|
| ticks | 否 | 1..20 | 按压时长（tick），默认 4 |

- 自动按压后松开，适合"跳一下"。
- 响应：`{}`（示例见 §10）；执行中若收到 `jump` 动作将取消本次按压。

#### sneak / sprint / swim / fly / fall_fly — 运动状态开关

```json
{"id": 4, "action": "sneak", "params": {"value": true}}
```

| 动作 | 参数 | 说明 |
|---|---|---|
| sneak | value | 潜行 |
| sprint | value | 疾跑（游戏规则：仅向前移动时生效） |
| swim | value | 游泳状态（需处于水中，否则 `302`） |
| fly | value | 飞行（需游戏模式允许飞行，否则 `302`） |
| fall_fly | value | 鞘翅滑翔（需装备鞘翅，否则 `302`） |

- 响应（sneak/sprint）：`{"applied": {"value": true}}`

#### look_at — 锁定目标（持续跟踪）

> v2 起 look_at 语义为**目标锁定**：设置后视角持续对准目标（每 tick 重新计算朝向），
> 玩家移动或目标移动时自动跟随，无需反复下发指令。原 `look`（yaw/pitch 绝对角度）已删除。

```json
{"id": 5, "action": "look_at", "params": {"x": 100, "y": 64, "z": -200}}
{"id": 6, "action": "look_at", "params": {"entity": 123456}}
{"id": 7, "action": "look_at", "params": {}}
```

| 形式 | 说明 |
|---|---|
| `{x, y, z}` | 锁定世界坐标（方块或任意点），视角持续对准该点 |
| `{entity: <id>}` | 锁定实体（id 来源：事件/后续 get_state 扩展），持续对准实体眼睛位置，实体移动视角跟随 |
| `{}` 或 `{unlock: true}` | 解除锁定，视角停在当前位置不再跟踪 |

规则：
- 新 `look_at` 指令覆盖旧目标；断线归零（§2.5）时解除锁定。
- 锁定期间玩家手动移动视角不会被覆盖（下个 tick 仍会重新对准目标）。
- `x/y/z` 与 `entity` 同时提供 → `103`（目标冲突）；提供 params 但既无目标也无 `unlock` → `102`；`unlock` 非布尔 → `103`。
- `entity` 不存在 → `304`；锁定期间实体消失/死亡 → **自动解除锁定**（不再跟踪）。
- 响应（锁定）：`{"yaw": 45.2, "pitch": -12.3, "target": {"type": "block", "x": 100, "y": 64, "z": -200}}`
  （`target.type` 为 `block` 或 `entity`；`entity` 时含 `id` 字段）
- 响应（解锁）：`{}`

### 5.2 瞬时动作类

#### attack — 攻击 / 挖掘

```json
{"id": 7, "action": "attack", "params": {"mode": "once"}}
```

| 字段 | 必填 | 可选值 | 说明 |
|---|---|---|---|
| mode | 是 | once / hold / release | once = 一次左键；hold = 持续按住；release = 松开 |

- **once**：准星指向实体 → 攻击实体；否则开始挖掘一次（然后自动松开）。
- **hold**：持续攻击实体 / 持续挖掘，直到收到 `release`。挖掘期间持续推送 `mine` 事件（进度），完成或中断推送 `mine_done`。
- **release**：停止攻击与挖掘。
- 响应：
  - `{"type":"attack_entity"}` — 攻击了实体
  - `{"type":"start_mine"}` — 开始挖掘
  - `{"type":"stopped"}` — release 生效

#### use_item — 使用物品（右键）

```json
{"id": 8, "action": "use_item", "params": {"slot": 4}}
```

| 字段 | 必填 | 范围 | 说明 |
|---|---|---|---|
| slot | 否 | 0..8 | 使用前切换到的槽位，省略 = 当前槽 |

- 响应：`{"hand":"main","success":true}`

#### interact_block — 右键方块

```json
{"id": 9, "action": "interact_block", "params": {"x": 10, "y": 63, "z": -5, "slot": 1}}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| x / y / z | 是 | 方块坐标 |
| face | 否 | 可选，省略由服务端自动计算 |
| slot | 否 | 使用前切换的槽位 |

- 响应：`{"success":true}`；方块不可交互/不可达 → `304`

#### interact_entity — 右键实体

```json
{"id": 10, "action": "interact_entity", "params": {"id": 123456, "slot": 2}}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| id | 是 | 实体 ID（当前版本通过事件/后续 get_state 扩展获取） |
| slot | 否 | 使用前切换的槽位 |

- 响应：`{"success":true}`；实体不存在 → `304`

#### drop — 丢弃物品

```json
{"id": 11, "action": "drop", "params": {"slot": 5, "count": 1}}
```

| 字段 | 必填 | 默认 | 说明 |
|---|---|---|---|
| slot | 否 | 当前槽 | 来源槽位 |
| count | 否 | 1 | 丢弃数量；**-1 = 整组** |

- 响应：`{"dropped": 1}`

#### hotbar — 切换主手槽位

```json
{"id": 12, "action": "hotbar", "params": {"slot": 3}}
```

- 响应：`{"slot":3}`；越界 → `304`

#### equip — 穿装备

> v2.1 新增（背包功能扩展）。槽位语义：slot 为来源槽（0-8 工具栏、9-35 背包）。

```json
{"id": 16, "action": "equip", "params": {"slot": 5, "armor": "chest"}}
```

| 字段 | 必填 | 范围 | 说明 |
|---|---|---|---|
| slot | 是 | 0..35 | 来源槽（0-8 工具栏、9-35 背包） |
| armor | 否 | head / chest / legs / feet | 目标盔甲槽；省略时按物品类型**自动穿戴**（原版 shift 点击语义） |

- 物品非装备 → `302`；指定 armor 但物品类型与槽位不符 → `302`
- 响应：`{"slot": 5, "armor": "chest"}`（armor 为实际生效槽）

#### move_item — 移动物品（背包 / 工具栏 / 盔甲 / 副手）

> v2.1 新增（背包功能扩展）。槽位语义：**0-8 工具栏、9-35 背包、36-39 盔甲（脚/腿/胸/头）、40 副手**（对齐原版玩家背包菜单布局）。

```json
{"id": 17, "action": "move_item", "params": {"from": 9, "to": 1}}
```

| 字段 | 必填 | 范围 | 说明 |
|---|---|---|---|
| from / to | 是 | 0..40 | 源/目标槽（可交换、可移动） |

- from == to → `103`；槽位越界 → `103`
- 走原版拾取/放置点击逻辑，服务端同步
- 响应：`{"from": 9, "to": 1}`

#### craft — 按配方合成

> v2.1 新增（背包功能扩展）。用**当前打开的容器**合成：个人 2x2（背包界面）或工作台 3x3（需先 `interact_block` 打开工作台）。

```json
{"id": 18, "action": "craft", "params": {"recipe": "minecraft:planks", "shift": true}}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| recipe | 是 | 配方 id（如 `minecraft:planks`） |
| shift | 否 | true = 尽量多合成（默认）；false = 单次 |

- 当前容器不支持合成（如箱子）→ `302`；配方不存在 → `304`
- 配方未解锁：**单机自动解锁**（无需手动研究）；连接服务器时未解锁 → `302`
- 响应：`{"sent": true, "container": 0, "recipe": "minecraft:planks"}`（服务端无回执，以背包物品变化为准）

#### chat — 发送聊天消息

```json
{"id": 13, "action": "chat", "params": {"message": "hello"}}
```

| 字段 | 必填 | 限制 | 说明 |
|---|---|---|---|
| message | 是 | ≤256 字符 | 聊天内容 |

- 限速：默认 ≥800ms 间隔，超限 → `303`
- 响应：`{"sent":true}`

---

### 5.3 查询类

#### get_state — 获取最小状态快照

```json
{"id": 14, "action": "get_state", "params": {}}
```

- 未进世界 → `301`；否则返回完整快照（见 §6）。

#### set_push — 控制 pos 事件推送

```json
{"id": 15, "action": "set_push", "params": {"pos": true}}
```

| 字段 | 必填 | 说明 |
|---|---|---|
| pos | 是 | true = 开启 pos 节流推送（默认开） |

- 响应：`{"pos":true}`

## 6. 状态快照（get_state 响应）

```json
{
  "protocol": 2,
  "player": {
    "position": {"x": 100.0, "y": 64.0, "z": -200.0},
    "rotation": {"yaw": 45.2, "pitch": -12.3},
    "motion": {"x": 0.0, "y": -0.05, "z": 0.0},
    "on_ground": true,
    "health": 20.0,
    "food": 20,
    "saturation": 5.0,
    "dimension": "minecraft:overworld",
    "gamemode": "survival",
    "alive": true,
    "selected_slot": 3,
    "abilities": {"flying": false, "fly_allowed": false}
  },
  "world": {"time_of_day": 6000}
}
```

| 字段 | 说明 |
|---|---|
| protocol | 协议版本 |
| player.position / rotation / motion | 位置 / 朝向 / 运动向量 |
| on_ground | 是否着地 |
| health / food / saturation | 生命 / 饥饿 / 饱食 |
| dimension | 维度 ID |
| gamemode | survival / creative / adventure / spectator |
| alive | 是否存活 |
| selected_slot | 当前主手槽 0..8 |
| abilities | 飞行状态与是否允许飞行 |
| world.time_of_day | 世界时间（tick） |

## 7. 事件推送

统一格式：

```json
{"type": "event", "event": "<名称>", "data": {...}}
```

| event | data | 触发条件 |
|---|---|---|
| `player_ready` | `{}` | 鉴权通过且已进世界；或进入世界时 |
| `pos` | `{"position":{...},"rotation":{...},"motion":{...},"on_ground":bool}` | 节流推送（默认 10 tick ≈ 0.5s，配置可调；`set_push` 可关） |
| `chat` | `{"sender":"Steve","message":"hi","self":false}` | 收到聊天消息（含自己发送的） |
| `damage` | `{"amount":5.0,"source":"cactus","health_after":15.0}` | 玩家受伤 |
| `death` | `{}` | 玩家死亡 |
| `respawn` | `{"dimension":"minecraft:overworld"}` | 重生 / 维度切换 |
| `game_mode` | `{"mode":"creative"}` | 游戏模式变化 |
| `mine` | `{"progress":0.3,"block":{"x":10,"y":63,"z":-5}}` | attack hold 挖掘中，进度 0..1 |
| `mine_done` | `{"block":{"x":10,"y":63,"z":-5},"destroyed":true}` | 挖掘完成（destroyed=true）或中断（false） |

## 8. 错误码

| code | 含义 |
|---|---|
| 101 | 未知动作 |
| 102 | 参数缺失 |
| 103 | 参数非法（范围 / 类型） |
| 104 | 消息格式错误（非法 JSON / 非对象） |
| 105 | 消息过大（>64KB） |
| 201 | 未鉴权 / 鉴权失败 |
| 301 | 游戏未就绪（未进世界） |
| 302 | 动作当前状态不可用（如无权限飞行、不在水中、未装备鞘翅） |
| 303 | 频率受限 |
| 304 | 目标非法（实体不存在 / 槽位越界 / 方块不可交互） |
| 401 | 内部错误 |

## 9. 速率限制（默认值，配置可调）

| 限制项 | 默认值 |
|---|---|
| 总消息 | 100 msg/s |
| chat | ≥800ms 间隔 |
| move / jump / look_at 等持续类 | 20 msg/s |
| attack | 20 msg/s（hold 期间不再重复请求） |
| 其他瞬时动作 | 20 msg/s |

超限返回 `303`。

## 10. 完整会话示例

```
客户端连接 ws://127.0.0.1:24777/?token=a1b2c3d4...

S→C: {"type":"hello","ok":true,"protocol":1,"mod":"keyboard","version":"0.1.0"}
S→C: {"type":"event","event":"player_ready","data":{}}

C→S: {"id":1,"action":"get_state","params":{}}
S→C: {"id":1,"ok":true,"result":{ ...快照... }}

C→S: {"id":2,"action":"move","params":{"forward":1}}
S→C: {"id":2,"ok":true,"result":{"applied":{"forward":1,"backward":0,"left":0,"right":0}}}
S→C: {"type":"event","event":"pos","data":{...}}   ← 节流推送持续到达

C→S: {"id":3,"action":"jump_once","params":{}}
S→C: {"id":3,"ok":true,"result":{}}

C→S: {"id":4,"action":"look_at","params":{"x":100,"y":64,"z":-200}}   ← 锁定目标，之后持续跟随
S→C: {"id":4,"ok":true,"result":{"yaw":45.2,"pitch":-12.3,"target":{"type":"block","x":100,"y":64,"z":-200}}}

C→S: {"id":5,"action":"look_at","params":{}}                            ← 解除锁定
S→C: {"id":5,"ok":true,"result":{}}

C→S: {"id":6,"action":"attack","params":{"mode":"hold"}}   ← 准星指向即目标（配合 look_at 已对准）
S→C: {"id":6,"ok":true,"result":{"type":"start_mine"}}
S→C: {"type":"event","event":"mine","data":{"progress":0.3,"block":{...}}}
S→C: {"type":"event","event":"mine_done","data":{"destroyed":true,...}}

C→S: {"id":7,"action":"chat","params":{"message":"hello"}}
S→C: {"id":7,"ok":true,"result":{"sent":true}}

C→S: {"id":8,"action":"move","params":{}}          ← 全零：停止移动
S→C: {"id":8,"ok":true,"result":{"applied":{"forward":0,"backward":0,"left":0,"right":0}}}
```

## 11. 安全说明

1. **仅监听 127.0.0.1**：只有本机进程能连接；token 泄露不影响远端（无法外网访问）。
2. **token 管理**：首启随机生成于 `config/keyboard.json` 并打印到日志；泄露后删除配置文件并重启游戏即可重新生成。
3. **断线归零**：连接断开时所有持续输入自动归零（默认开启），避免 AI 崩溃后玩家卡在移动/跳跃状态。
4. **无作弊能力**：协议不含传送、改游戏模式、刷物品等能力；全部动作为合法玩家输入。

## 12. 变更记录

> **v2.1 增补（2026-08-23，非破坏性，protocol 保持 2）**：背包功能扩展——新增 `equip`（穿装备）、`move_item`（背包/工具栏/盔甲/副手物品移动）、`craft`（按配方一键合成，单机自动解锁配方）；§5.4 预留移除"背包全量/物品合成"。

> **v2（2026-08-23，破坏性变更，protocol 1 → 2）**：视角与挖掘部分重做——

> ② 删除 `mine_block`（指定坐标挖掘 + 自动对准 + 障碍判定），挖掘一律走 `attack`（准星指向即目标，配合 look_at 锁定精准挖掘）。
>
> v1 修订（2026-08-14）：取消服务端权限体系（原 §12 管理员指令、305 错误码、`automation` 事件），mod 仅客户端运行，动作不受权限门控。
